# ⚡ CyberTec Admin Panel

CyberTec es un **panel de administración estilo gamer oscuro** diseñado para gestionar un catálogo de productos tecnológicos de forma clara, moderna e interactiva.  
El proyecto utiliza **HTML, CSS y JavaScript** separados para mantener una arquitectura limpia y ordenada.

---

## 📌 Características

- 🎮 **Diseño gamer oscuro** con colores neón y gradientes.
- 📊 **Dashboard** con estadísticas rápidas y accesos.
- 📦 **Gestión de Inventario** con tablas, filtros y alertas de stock.
- 🛒 **Catálogo de Productos** con tarjetas interactivas y filtros dinámicos.
- ➕ **Agregar Producto** con formulario completo y vista previa en tiempo real.
- ⚡ **Interactividad con JavaScript**: validaciones, filtros, toasts, temas.
- 📱 **Responsive Design** adaptable a móviles y tablets.

---

## 🛠️ Tecnologías usadas

- **HTML5** → estructura y contenido.
- **CSS3** → estilos modernos, responsive, dark theme.
- **JavaScript (ES6)** → lógica, validaciones y animaciones.
- **JSON (simulado)** → estructura de datos (productos, usuarios, inventario).
